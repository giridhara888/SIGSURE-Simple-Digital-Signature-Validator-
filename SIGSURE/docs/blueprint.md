# **App Name**: SignVerify

## Core Features:

- Key Pair Generation: Generate a new public/private key pair for digital signatures using Java cryptography libraries.
- Digital Signature Creation: Create a digital signature for a given input (e.g., a file or text) using the private key.
- Signature Validation: Verify a digital signature against a given input and public key, indicating whether the signature is valid.
- Input Handling: Accept files or text input from the user for signature creation and validation.
- Key Management: Securely store and retrieve generated key pairs.
- Clear Validation Display: Provide a clear and intuitive visual indication of whether a signature is valid or invalid, with explanations if possible.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and security, essential for a signature validator.
- Background color: Light gray (#F5F5F5), providing a clean, professional backdrop to enhance readability.
- Accent color: Vibrant orange (#FF9800) to draw attention to calls-to-action like the key generation or file validation buttons.
- Font pairing: 'Inter' (sans-serif) for headings and 'Literata' (serif) for the body for enhanced readability
- Use security-themed icons (e.g., locks, keys, shields) to reinforce the purpose and trustworthiness of the application.
- Employ a clean and structured layout with clear visual hierarchy to guide the user through the key generation, signing, and validation processes.
- Incorporate subtle animations, such as a loading spinner during signature validation or a brief highlight upon successful validation, to enhance the user experience.
